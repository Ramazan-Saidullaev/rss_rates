# Currency Rates KZ Airflow

Apache Airflow DAG для автоматизированной ежедневной загрузки курсов валют Национального банка Республики Казахстан в PostgreSQL.

## Возможности

- **Автоматический запуск:** ежедневно в 08:00 по времени `Asia/Almaty`.
- **Источник данных:** официальный XML-источник Национального банка Казахстана — [nationalbank.kz/rss/rates_all.xml](https://www.nationalbank.kz/rss/rates_all.xml).
- **Извлечение данных:** код и название валюты, курс и дата.
- **Хранилище:** PostgreSQL, таблица `currency_rates_kz`.
- **Повторные попытки:** 2 попытки при ошибке выполнения.
- **Защита от дубликатов:** если данные за соответствующую дату уже загружены, повторная загрузка пропускается.

## Принцип работы

1. Airflow запускает DAG по установленному расписанию.
2. DAG получает XML с курсами валют Национального банка Казахстана.
3. Из XML извлекаются необходимые данные: код валюты, название, курс и дата.
4. Данные записываются в таблицу `currency_rates_kz` в PostgreSQL.
5. Перед загрузкой проверяется наличие данных за соответствующую дату, чтобы избежать повторной загрузки.

## Настройка подключения к PostgreSQL

Перед запуском DAG необходимо создать подключение `postgres_default` в интерфейсе Apache Airflow.

В разделе **Admin → Connections** укажите следующие параметры:

| Параметр | Значение |
|---|---|
| Connection Id | `postgres_default` |
| Connection Type | `Postgres` |
| Host | Адрес сервера PostgreSQL |
| Schema | Название базы данных |
| Login | Имя пользователя БД |
| Password | Пароль пользователя БД |
| Port | Порт PostgreSQL |

Замените параметры подключения на значения, соответствующие вашей конфигурации PostgreSQL.

| Параметр | Значение |
|---|---|
| DAG ID | `currency_rates_kz` |
| Часовой пояс | `Asia/Almaty` |
| Время запуска | 08:00 |
| Периодичность | Ежедневно |
| Количество повторных попыток | 2 |

## Результат

После успешного выполнения DAG в PostgreSQL сохраняются курсы валют Национального банка Казахстана. Проверка наличия данных за дату позволяет пропускать повторную загрузку уже обработанных данных.

## Используемые технологии

- **Apache Airflow** — планирование и оркестрация ETL-процесса.
- **PostgreSQL** — хранение данных о курсах валют.
- **XML** — формат исходных данных Национального банка Казахстана.
